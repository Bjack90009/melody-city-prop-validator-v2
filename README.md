# 爱乐之城 · 套装化表演道具验证器 V2.1

本目录当前对应独立场景 `SCN-PROP-V2.1-20260821`。它用于体验套装化规则，不覆盖当前 V1 验证器或公开试玩版本。

公开试玩：https://bjack90009.github.io/melody-city-prop-validator-v2/

## 启动

1. 运行 `start.ps1`。
2. 浏览器打开脚本输出的本地 HTTP 地址。
3. 工具自动读取 `data/爱乐之城-表演道具验证配置-V2.1.xlsx`。

不要直接双击 `index.html`。若自动读取失败，可在“工具与配置”中手动加载工作簿。

## V2.1 核心规则

- 48 件道具：键盘 7、弦乐 13、管乐 11、打击 8、舞台装饰 9。
- 四个基础声部套装和六个进阶乐团套装。
- 初始 1 紫 1 蓝必然共享套装、能够同时放入中央 2×4，并可激活套装 1 级。
- 同名道具不产生第二实例；重复获得自动转化为唯一实例的升级进度。
- 每 3 场表演进入一次强制三选一；先按红 5%、金 15%、紫 30%、蓝 50% 抽本组品质，同一组中出现的道具均为该品质。
- 奖励不做持有、套装或背包适配定向；默认有 50% 概率以“解锁 2 格”替代其中 1 个道具选项，概率和格数均由规则配置表控制。
- 标签2字段保留但值为空，不显示且不参与规则。
- 先结算套装固定值，再结算能力百分比；逐件最终表演值向下取整。
- 能力值按品质、覆盖种类数、作用范围和目标上限统一折算；同条件下单种类能力系数为四种类的 2 倍。

## 配置表

- `规则配置`：背包、初始区域、奖励间隔、扩格、升级和日志参数。
- `套装配置`：套装层级、固定值和高层特殊效果。
- `品质配置`：品质、组抽取概率、基础锚点和界面颜色。
- `道具配置`：48 件道具的名称、种类、形状、套装、能力和五级数值。
- `表演规则`、`发挥档位`、`现场事件`：单场随机性和极简互动。
- `种类表演特性`：只影响表演表现，不参与套装和能力判定。

V2.1 工作簿是体验器当前数据源。修改后可在页面中重新加载，不需要改 `app.js`；V2.0 工作簿继续保留用于对照。

## 界面验证点

- 背包上方显示基础、套装和能力三段分数。
- 套装条显示已激活层级、成员数和固定值，并可点击筛选仓库。
- 仓库、详情和奖励三选一均展示套装、能力和占格图形；奖励卡显示各套装的已拥有成员数。
- 奖励面板可以折叠查看背包和详情，确认前所有状态修改操作锁定。
- 背包中的能力已激活道具名称使用激活色；获得套装或能力加成的最终表演值使用增益色。
- 详情显示当前等级能力和逐件贡献公式。
- 表演日志记录每场体力、基础分、随机变化和最终得分。
- “解锁至”可以直接调整开放格数量。

## 图标边界

V2 规则验证阶段复用 V1 卡通图标库；新增 ID 暂时使用同类图标占位。待套装、数量和名称通过体验确认后，再进入逐件图标定稿，避免在规则尚未稳定时重复制作美术资产。
